# Support

## Before asking for help

Read the [README](./README.md), especially the setup and environment-variable
sections. Confirm that you are using a supported Node.js version and run:

```sh
npm run typecheck
npm run lint
npm run build
```

For authentication issues, verify `AUTH_SECRET`, provider credentials, the
database connection, and the exact callback URL. For deployment issues, check
the host's environment variables and migration logs.

## Getting help

- Search existing GitHub issues and discussions first.
- Use GitHub Discussions for setup questions and general usage.
- Open an issue for a reproducible bug.
- Use the process in [SECURITY.md](./SECURITY.md) for vulnerabilities.

When asking for help, include your operating system, Node.js version, browser,
deployment provider, relevant command output, and reproduction steps. Remove
secrets, tokens, cookies, database URLs, and personal data before posting.

CalEasy is maintained by volunteers, so response times may vary.
